About VHELIBS

VHELIBS (Validation Helper for LIgands and Binding Sites) analyses protein–ligand complexes from PDB structures. For every ligand it finds, it evaluates the ligand itself and its surrounding binding site against real-space and refinement quality metrics, then classifies each as Good, Dubious, or Bad based on thresholds you control. Results can then be inspected residue-by-residue in an interactive 3D viewer, together with the experimental electron density around each region.

How an analysis works

You can enter PDB IDs, UniProt accessions, or a mix of both. A UniProt accession is automatically resolved (via the RCSB Search API) to every PDB structure associated with it, and each of those structures is analysed individually.

For each PDB ID, VHELIBS downloads the mmCIF model (from RCSB, or from PDB-REDO if that option is checked) together with per-residue real-space validation statistics (from PDBe's EDS validation report, or from PDB-REDO's own re-refinement data). Ligands that are known solvents, buffers, ions, or crystallisation additives — or that are covalently bound to the protein chain — are filtered out using the built-in metal/blacklist tables rather than being scored as ligands. Remaining ligands are grouped into complexes (covalently linked HETATM groups count as one ligand), and every residue within the binding-site distance cutoff is collected as that ligand's binding site.

Classification criteria

Each residue accumulates one "fail point" per criterion it does not meet:

MetricDefault thresholdEffect on score
RSR (real-space R-factor)≤ 0.24 good · 0.24–0.40 → +1 · > 0.40 → +2+1 or +2
RSCC (real-space correlation coefficient)> 0.9+1 if below
Occupancy= 1.0+1 if below · flagged separately if > 1.0
R-free< 1.0+1 if above

A residue's total score decides its bucket: 0 → Good, 1 to Tolerance → Dubious, above Tolerance → Bad (Tolerance defaults to 2). A ligand or binding site then inherits the worst classification among its own residues: it is Bad if any residue is Bad, otherwise Dubious if any residue is Dubious, otherwise Good. Residues with missing validation data, or with occupancy above 1.0, are treated as an error condition rather than scored numerically, and are listed separately as rejected.

Advanced (optional) checks

These are disabled by default and can be turned on under Advanced options on the Analysis tab. Each adds its own +1 fail point when the residue's structure fails it:

MetricDefault thresholdNotes
OWAB< 50Occupancy-weighted average B-factor, per residue
Resolution≤ 3.5 ÅStructure-wide, from RCSB/PDB-REDO refinement stats
R-diff≤ 0.05|R-free − R-work|, flags possible over-refinement
DPI< 0.42Diffraction-component precision index, estimated from cell volume, atom count, reflection count and R-free

3D Viewer

The Viewer tab renders the model with Mol*, with independent, toggleable layers for the protein, ligand, and binding site. When a structure has an associated 2Fo-Fc electron density map, it can also be overlaid, segmented per region (ligand / binding site / components to examine) rather than shown as one whole-model surface. Density is streamed on demand from EBI's density server as small boxes around each region and clipped to a sphere around every atom, so you're only ever looking at density that belongs to the components you're inspecting. The contour level (isovalue, in σ) and the per-atom mask radius are both adjustable live from the sidebar. If a structure contains more than one ligand, opening the 3D view for one of them shows only that ligand and its own binding site — any other ligand present in the structure is left out of the scene entirely.

Data sources

  • Structure files: RCSB PDB (mmCIF format)
  • Validation statistics: PDBe validation reports
  • Re-refined structures & statistics: PDB-REDO (optional alternative to RCSB)
  • Electron density maps: EBI's density server (segmented 2Fo-Fc/Fo-Fc volumes)
  • 3D visualisation: Mol* Viewer
